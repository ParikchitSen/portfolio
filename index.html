Intelligent Traffic Moderator

A hybrid RL + optimization system for adaptive traffic signal control

A traffic signal controller that pairs a DQN agent with a Scipy (HiGHS solver) based linear programming optimizer. YOLOv8 and OpenCV extract lane-wise vehicle counts and queue density from live video or SUMO simulation, the DQN identifies which phase is most urgent, and the LP layer computes exact green-time allocations under cycle-time and min/max green constraints. Built with a FastAPI backend, PostgreSQL, and a real-time React dashboard, and validated end-to-end in SUMO before targeting real traffic video.

  • YOLOv8
  • Reinforcement Learning
  • Linear Programming
  • SUMO
Completed

SoilSense AI

A soil-scanning app with an AI advisor that runs offline

A React Native front end paired with a local retrieval-augmented generation backend. A user scans a soil sample and the app returns crop recommendations, treatment suggestions, and field advice, grounded in agricultural reference material from NARC, MoALD, and the FAO, served through Ollama running quantized Qwen2.5 and Gemma 2 models on a local GPU.

  • React Native
  • Ollama
  • RAG
